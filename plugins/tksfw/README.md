scripts locate from `$CLAUDE_PROJECT_DIR` or by walking up from the current directory to `AGENTS.md`.
The plugin directory itself is never written to (Claude Code replaces it on update).

Install: see `docs/distribution.md` in the TKSfw repository. Plugin hooks are not trusted
automatically in Codex — review and trust them in `/hooks` after installing or updating.
